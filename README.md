# 🖥️ SE1 Exam Prep — L2 Informatique

Interactive Operating Systems (SE1) exam preparation platform for L2 Informatique students at Université Constantine 2.

---

## 🌟 Features

- ⚙️ Complete process scheduling revision (FCFS, SJF, SRTF, RR, Priorities)
- 🧮 Memory management — pagination, segmentation, virtual memory
- ⚡ Interruptions chapter — full theoretical course (PSW, LPSW, SVC, ISR)
- 📊 Visual Gantt diagrams and page replacement tables
- 🔢 Dedicated formulas page with step-by-step calculation rules
- 📝 Mock exam with hidden answers (styled after real 2025 control)
- 🌙 Dark / Light mode
- 🌍 Bilingual support (French / Arabic)
- 📱 Responsive design
- ⚡ Single-file — no install, no dependencies
